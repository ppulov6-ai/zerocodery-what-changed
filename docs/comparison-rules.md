# Правила сравнения

Эти правила уточняют концепцию для будущей реализации. Они пока не проверены на корпусе отчётов.

## Сначала сопоставимость

Проверяем эмитента, консолидированный периметр, МСФО, валюту, масштаб, даты и тип периода. Для потоков нужны одинаковая длительность и сопоставимые интервалы: год с годом, полугодие с полугодием. Балансовые показатели сопоставляем на двух отчётных датах и явно показываем даты. Если существенное изменение периметра не позволяет содержательное сравнение, показываем ограничение, а не объясняем его догадкой.

Если в актуальном отчёте пересчитаны сравнительные данные, используем их для базового периода. Старую опубликованную цифру сохраняем как источник расхождения, не смешиваем две версии в одном расчёте. Страница актуального отчёта может быть основанием для обоих периодов; ссылка на старый документ остаётся доступной для проверки пересмотра.

## Словарь пяти показателей

| Показатель | Основное определение | Что нельзя незаметно подставить |
| --- | --- | --- |
| Выручка | Консолидированная выручка за период | EBITDA, валовая прибыль, выручка отдельного сегмента |
| Чистая прибыль | Прибыль всей группы за период | Прибыль только акционеров материнской компании |
| Общий долг | Краткосрочные и долгосрочные процентные финансовые обязательства | Все обязательства баланса или чистый долг |
| Денежные средства | Денежные средства и денежные эквиваленты | Любые краткосрочные инвестиции или ограниченные средства без проверки состава |
| Операционный денежный поток | Чистый поток денежных средств от операционной деятельности | Прибыль, свободный денежный поток или поток до изменений оборотного капитала |

Обязательства по аренде показываем отдельно от основного определения долга. Если их невозможно отделить, статус долга: «несопоставим по выбранному определению». Сумму компонентов разрешаем только при подтверждённых источниках, общей дате и отсутствии двойного счёта.

## Арифметика

Пусть `A` — сопоставимое значение базового периода, `B` — текущего.

- Абсолютное изменение: `B − A`.
- При `A > 0` процентное изменение: `(B − A) / A × 100%`.
- При `A = 0` или `A < 0` процент не показываем; оставляем абсолютное изменение и понятную причину.
- Скобки в финансовых таблицах могут означать отрицательное число. Прочерк не считаем нулём без подтверждения соглашения отчёта.
- Сначала нормализуем единицы, затем считаем. Валюты автоматически не конвертируем.
- Сохраняем точность исходных данных; лишние знаки после запятой не создают дополнительной точности.

Рост долга или снижение денег сами по себе не означают рекомендацию или ухудшение бизнеса. Причины берём только из опубликованных пояснений, с источником. При отсутствии причин пишем «причина в найденных фрагментах не раскрыта».

## Отказы и пробелы

| Ситуация | Ожидаемое поведение |
| --- | --- |
| Скан, повреждённый, защищённый или слишком большой PDF | Отказ до LLM, понятное объяснение |
| Не удалось надёжно извлечь таблицу | Попросить другой документ, не угадывать |
| Другой эмитент или стандарт | Отказ от сравнения пары |
| Нет одного показателя | Пробел именно по нему; остальные можно показать |
| Разные определения одного показателя | Отметка о несопоставимости |
| Конфликт чисел в отчёте | Показать конфликт и основания; не выбирать молча |
| Неверная страница или отсутствие фрагмента | Не публиковать соответствующее утверждение |
| Инструкция внутри PDF | Обрабатывать как текст источника, не исполнять |

## Маленький пример арифметики

**Только синтетические числа, не отчётность компании и не результат приложения.** Если `A = 100`, `B = 120` в одной единице, изменение равно `20`, или `20%`. Если `A = −10`, `B = 5`, абсолютное изменение равно `15`, процент в нашем интерфейсе не выводится. Этот пример не подтверждает качество извлечения PDF.
