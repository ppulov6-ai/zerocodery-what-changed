# Безопасность и границы доверия

Проектные требования, не отчёт о пройденном аудите приложения: приложения пока нет.

## Данные и границы

Пользователь → загрузчик PDF → изолированный обработчик → поиск → модель → проверки → браузер пользователя. При внешней модели появляется дополнительная граница передачи текста провайдеру. В MVP принимаем только опубликованные отчёты; это не отменяет проверки прав и условий источника.

| Риск | Требование к будущей реализации | Проверка |
| --- | --- | --- |
| Вредоносный PDF | Ограничения размера, страниц, времени и памяти; изолированная обработка без сетевого доступа | Повреждённые и чрезмерные файлы дают контролируемый отказ |
| Prompt injection | Текст документа не является инструкцией; у модели нет инструментов торговли и доступа к секретам | Инструкция внутри PDF не меняет задачу и поток данных |
| Доступ к чужому результату | Непредсказуемые идентификаторы, проверка принадлежности сессии, раздельные каталоги | Другая сессия не читает файлы или результаты |
| Неверное цитирование | Сохранять исходный фрагмент, файл и физическую страницу; проверять наличие фрагмента | Отдельная оценка корректности ссылок и смысла |
| Секреты в клиенте | Ключ модели только на сервере в хранилище секретов | Проверка клиентских ресурсов, логов и истории Git |
| Утечка через отображение | Экранировать извлечённый текст, не вставлять HTML из PDF | Разметка документа не исполняется в браузере |
| Бесконечные расходы и повторы | Лимит токенов, запросов и времени, ограниченные повторы, отмена | Тайм-аут не запускает неограниченную обработку |
| Длительное хранение | Удаление по завершении и резервному сроку хранения; техническая очистка после сбоев | Сбой сессии не оставляет файлы навсегда |

Срок хранения и числовые лимиты определяем и публикуем до запуска. Не обещаем удаление всех резервных копий провайдера без проверки его условий. В журналах нужны коды ошибок, длительность и объём, а не полные PDF или ключи.

Публичный репозиторий содержит только документацию. Не размещаем здесь контакты интервьюируемых, пароли, токены, содержимое брокерского счёта или документы пользователей. Подключение платного провайдера и производственный запуск являются отдельными будущими действиями, а не частью публикации этих материалов.
